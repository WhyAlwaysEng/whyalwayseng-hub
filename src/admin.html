01 หมวดหมู่ซอฟต์แวร์ (Category)
หน้าร้านเจนปุ่มกรองให้อัตโนมัติ
🖥️ Desktop App

โปรแกรมทั่วไปที่มีหน้าต่าง GUI (Tauri, Electron, Qt, WinForms, Flutter, C#) มีปุ่มและเมนูให้คลิกใช้งาน

⌨️ CLI Tool

โปรแกรมรันบน Terminal / Command Prompt ไม่มีหน้าต่าง UI เช่น git, gh, ffmpeg, ripgrep, curl

🛠️ Developer Tool

เครื่องมือช่วยพัฒนาซอฟต์แวร์ เช่น Code Editor, API Tester, Debugger, SDK, Database Management

🔧 Utility

โปรแกรมอรรถประโยชน์ เช่น เครื่องคิดเลข, โปรแกรมแตกไฟล์, Screen Recorder, File Renamer

🎮 Game

เกมทุกรูปแบบ (2D/3D, Unity, Godot, Unreal), เกมอินดี้ หรือ Emulator โปรแกรมจำลองเกม

🤖 AI & Machine Learning

ซอฟต์แวร์ประมวลผลด้วย AI, LLM, Vision, Image Generation, Voice Assistant, หรือ Machine Learning

⚡ Automation & Bot

บอท Discord, บอท Telegram, Web Scraper, Auto Task, หรือสคริปต์ทำงานอัตโนมัติ

🛡️ Cybersecurity

เครื่องมือความปลอดภัย, Network Scanner, Password Manager, VPN, ตรวจสอบช่องโหว่

💡
พิมพ์ชื่อหมวดหมู่เองได้อิสระ (+ Custom Category): หากแอปของคุณไม่ตรงกับตัวเลือกมาตรฐาน สามารถกดปุ่ม + Custom Category แล้วพิมพ์หมวดหมู่ใดก็ได้ เช่น "Media Player", "Audio Editor", "Design", "Education" หน้าเว็บจะสร้าง Filter Tab ใหม่บนหน้าร้านให้ทันที!
02 ระบบปฏิบัติการที่รองรับ (Platforms)
🪟 Win (Windows)

ไฟล์ .exe, .msi, .zip หรือ winget

🍎 Mac (macOS)

ไฟล์ .dmg, .pkg หรือ brew

🐧 Linux

ไฟล์ .deb, .rpm, .AppImage, .tar.gz

🌐 Web

เว็บแอปพลิเคชัน ใช้งานผ่าน Browser

🤖 Android

ไฟล์ติดตั้ง .apk หรือ .aab

📱 iOS

ไฟล์ .ipa หรือ App Store Link

✨ ข้อแนะนำเพิ่มเติม
  • ตั้งชื่อ Tags: ใส่คีย์เวิร์ดภาษาอังกฤษคั่นด้วยจุลภาค เช่น discord, bot, automation เพื่อให้ช่องค้นหาบนเว็บหลักค้นเจอได้รวดเร็ว
  • ปุ่ม Quick Download: ระบบจะเลือกไฟล์ติดตั้งให้ตรงกับระบบของผู้ใช้โดยอัตโนมัติจาก Platform ที่คุณติ๊กไว้
  • Featured App ⭐: ติ๊กเลือกแอปเด่นเพื่อนำขึ้นไปแสดงในแถวบนสุดของหน้าร้าน
