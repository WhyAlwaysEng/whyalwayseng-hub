# ⚡ GitHub Software Store Hub

A zero-backend software distribution store that uses GitHub Repositories and Releases as its source of truth. No database, no admin panel, and no runtime API rate limits.

---

## 🌟 Key Features

- **Zero-Backend & Static-First:** GitHub Actions fetches metadata and generates a static `catalog.json` alongside pre-rendered HTML pages for each app (`/apps/<slug>/`).
- **No API Rate Limits:** Client browsers read from static JSON cached on CDN/GitHub Pages instead of querying GitHub API at runtime.
- **Instant Search & Filtering:** Powered by Fuse.js for fuzzy keyword searching, categories, platform filters (Windows/macOS/Linux), and sorting.
- **Smart OS & Architecture Detection:** Recommends the appropriate download installer automatically with 1-click downloads.
- **Security-First:** Content-Security-Policy (CSP) enforced, strictly sanitized release notes and Markdown via DOMPurify + marked.js, and Alpine CSP build.
- **PWA & Offline Ready:** Service worker caching and web application manifest.
- **i18n & Dark Mode:** English and Thai localization support with system and manual dark mode toggle.

## 📂 Project Structure

```

│   ├── workflows/          # GitHub Actions CI/CD workflows
│   └── ISSUE_TEMPLATE/     # Templates for submitting apps and reporting bugs
├── data/

│   └── th.json             # Thai UI strings

│   ├── build-catalog.mjs   # Fetches GitHub API and builds catalog.json

├── src/
│   ├── app.js              # Alpine CSP stores & components
│   ├── styles.css          # Tailwind CSS entrypoint
│   ├── sw.js               # Service Worker
│   └── manifest.webmanifest# PWA Manifest
├── projects.json           # Curated list of applications
└── dist/                   # Built production static site
```

## 🚀 Getting Started

### Prerequisites
- Node.js 22 or higher
- npm 10 or higher

### Installation
```bash
git clone <your-repo-url>
cd software-store
npm install
```

### Development & Build Commands

| Command | Description |
|---|---|
| `npm run validate` | Validates `projects.json` against the JSON schema and checks regex syntax |
| `npm run build:catalog` | Fetches release and repo data from GitHub and produces `data/catalog.json` |
| `npm run build:css` | Compiles and minifies Tailwind CSS into `dist/styles.css` |
| `npm run build:site` | Generates static HTML pages for all apps, sitemap, and RSS feed |
| `npm run build` | Runs the full build pipeline (`validate` → `catalog` → `site` → `css`) |
